# Study

Self-study notes connecting **the data-science engine you built** with **the markets you're
selling into**, plus the craft of turning analysis into paid work. Written to be read, not
skimmed. Every vertical note cross-links back to `data science/` by number.

## The folders
- **`data science/`** — every algorithm in `src/tabular/analytics/`, ordered introduction →
  advanced (00–10). Intuition → real stats/ML → what our code does → reading output →
  pitfalls → marketing angle. **Start here.**
- **`digital marketing/`** — the marketer's world (funnel, metrics, channels, analytics
  stack, attribution) and the payoff map of problem → algorithm. Your **primary vertical
  (agencies)**.
- **`ecommerce/`** — the largest, easiest vertical: business model, metrics, the data you
  receive, the analysis lifecycle, where DS helps.
- **`saas/`** — subscription businesses: MRR/churn/NRR, usage data, the churn early-warning
  flagship.
- **`nonprofits/`** — richest *public* data (IRS 990s), donor retention, mission-framed
  findings.
- **`delivering-insights/`** — the craft: turning a number into a finding, structuring a
  report clients act on, and the credibility guardrails. **This is your real bottleneck.**

## Service-pitch documents (client-facing)
One per vertical — what you actually offer, in language you can lift into a call or the
website:
- `digital marketing/service-pitch.md` (agencies — white-label + overflow)
- `ecommerce/service-pitch.md`
- `saas/service-pitch.md`
- `nonprofits/service-pitch.md`

## Suggested path
1. `data science/00 → 10` in order — the toolkit and its limits.
2. `digital marketing/` then your priority verticals (`ecommerce`, `saas`, `nonprofits`) —
   each ends in a problem→algorithm map and a service pitch.
3. `delivering-insights/` — the last mile where deals are won or lost.
4. Re-read each vertical's `04-where-data-science-helps` (or `02`) before a client call.

## The one-line thesis
The market has infinite dashboards and almost no interpretation. You built the interpretation
layer (descriptive → diagnostic → predictive → causal). These notes teach you to explain it
in each buyer's language, match it to the data they actually have, and deliver it so they pay
again.
